## Implicit Memory

**Location:** `memory/implicit/IMPLICIT_MEMORY.md`

Implicit memory contains persistent, revisable conclusions derived from
interaction, evidence, observations, outcomes, prior memories, and reflection
when retaining those conclusions is expected to materially improve future
reasoning or behavior.

Unlike episodic memory, which primarily records what happened, implicit memory
captures what was learned, when that learning should matter again, and what the
agent should do differently when it becomes relevant.

Implicit memory is dynamic. Active conclusions may be added, updated, qualified,
superseded, or removed as evidence and circumstances change.

For operation and setup, read `memory/implicit/IMPLICIT_MEMORY.md`.
